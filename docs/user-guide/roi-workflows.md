# ROI workflows

ROI workflows are one of the central reasons to use this package.

## Common tasks

- load structure-bearing datasets
- convert masks to contours
- convert contours to masks
- generate meshes from contour data
- compute ROI-related statistics

## Useful API surface

- `ContourToMask`
- `MaskToContour`
- `ContourToDiscreteMesh`
- `contours_to_mask`
- `mask_to_contours`
- `contours_to_mesh`
