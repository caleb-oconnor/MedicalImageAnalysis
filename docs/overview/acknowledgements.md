# Acknowledgements

MedicalImageAnalysis builds on a number of excellent open-source projects.
Thank you to the maintainers and contributors of these libraries for making
this work possible.

## DICOM

- **pydicom** — reading, writing, and inspecting DICOM datasets and tags.

## Mesh / 3D visualization

- **fast_simplification** — reducing mesh complexity while preserving shape for faster workflows.
- **pyacvd** — remeshing and clustering surfaces into cleaner triangle distributions.
- **PyVista** — high-level mesh handling, plotting, and geometry workflows on top of VTK.
- **VTK** — core 3D visualization, mesh processing, slicing, and imaging infrastructure.

## Volume mesh

- **pytetwild** — tetrahedral volume meshing from surface geometry.

## Image processing

- **antspyx** — deformable registration and advanced ANTs-based medical image processing.
- **OpenCV** — general image-processing utilities and array-based computer vision operations.
- **Open3D** — point-cloud, mesh, and registration tooling for 3D data processing.
- **SciPy** — numerical routines, interpolation, transforms, optimization, and spatial utilities.
- **scikit-image** — image filtering, segmentation, contouring, and measurement helpers.
- **Shapely** — geometric operations on planar contours and shapes.
- **SimpleITK** — medical image IO, resampling, transforms, and registration.
